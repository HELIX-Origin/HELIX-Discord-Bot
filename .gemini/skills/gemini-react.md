# Gemini Skills

This directory contains skills specifically for Google Antigravity (Gemini) integration with HELIX CLI.

## Available Gemini Skills

- **gemini-react**: React/TypeScript component generation
- **gemini-discord**: Discord bot code generation
- **gemini-web**: Web page and component generation
- **gemini-desktop**: Desktop app code generation
- **gemini-game**: Game engine script generation

Each skill provides Gemini with context about the project type and framework for better code generation.
