# Rule 05: Documentation Standards & Root Landing

## Mandatory Invariants
1. **Minimal Root Landing**: Root `README.md` must remain a concise landing page with quick links, status indicators, and feature highlights.
2. **Dedicated Technical Docs**: In-depth documentation lives exclusively in `docs/` (`docs/discord-bot.md`, `docs/plugin-system.md`, `docs/web-dashboard.md`, etc.).
3. **Cross-Agent Consistency**: Any architectural or schema updates must be reflected in `AGENTS.md`, `.agents/`, `.gemini/`, `.copilot/`, and `.opencode/`.
