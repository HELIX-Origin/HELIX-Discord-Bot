# Copilot Agents

This directory contains agent files specifically for GitHub Copilot integration with HELIX CLI.

## Available Copilot Agents

- **copilot-suggest**: Agent for Copilot code suggestions
- **copilot-chat**: Agent for Copilot chat interactions
- **copilot-complete**: Agent for Copilot automatic completion

Each copilot agent provides context-aware suggestions and completions for supported project types.
