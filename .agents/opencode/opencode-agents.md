# Opencode Agents

This directory contains agent files specifically for opencode configuration and management.

## Available Opencode Agents

- **opencode-config**: Agent for managing opencode.json configuration
- **opencode-skills**: Agent for managing skills and capabilities
- **opencode-plans**: Agent for plan tracking and roadmap management
- **opencode-bugs**: Agent for bug tracking within opencode
- **opencode-templates**: Agent for template management

Each opencode agent provides configuration details and management commands specific to the HELIX CLI system.
