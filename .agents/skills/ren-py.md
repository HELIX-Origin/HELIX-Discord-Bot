# Skill: Ren'Py Visual Novel Development

## Overview
Standards and code recipes for creating narrative games and visual novels with the Ren'Py engine (v8+ Python 3 runtime).

## Project Structure
- `game/script.rpy`: Primary narrative labels and branching choices.
- `game/screens.rpy`: Custom UI widgets, dialogue windows, inventory screens.
- `game/options.rpy`: Game title, window size, save directory, transitions.
- `game/gui.rpy`: Fonts, accent colors, text sizes, and box margins.

## Narrative & Python Integration Example (`game/script.rpy`)
```renpy
define e = Character("Eileen", color="#c8ffc8")
define h = Character("Helix", color="#c8c8ff")

default affinity_score = 0

init python:
    class InventoryItem:
        def __init__(self, name, description):
            self.name = name
            self.description = description

    def boost_affinity(amount):
        global affinity_score
        affinity_score += amount

label start:
    scene bg room with fade
    show eileen happy at left
    
    e "Welcome to our visual novel project generated by HELIX CLI!"
    
    menu:
        "I'm ready to learn more.":
            $ boost_affinity(5)
            e "Great! Let's build something amazing together."
        "Tell me about the engine.":
            $ boost_affinity(2)
            e "Ren'Py supports deep Python scripting along with intuitive narrative tags."

    "Your affinity score is now [affinity_score]."
    return
```

## Best Practices
- Declare game state variables using `default <var> = <value>` rather than `define` so they are properly saved in player save files.
- Keep assets organized in `game/images/` and use automatic image name resolution (`image bg room = ...`).
