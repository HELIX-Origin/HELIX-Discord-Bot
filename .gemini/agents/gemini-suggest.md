# Gemini Agents

This directory contains agent files specifically for Google Antigravity (Gemini) integration with HELIX CLI.

## Available Gemini Agents

- **gemini-suggest**: Agent for Gemini code suggestions
- **gemini-chat**: Agent for Gemini chat interactions  
- **gemini-complete**: Agent for Gemini automatic completion

Each gemini agent provides context-aware suggestions and completions for supported project types.
