# Copilot Skills

This directory contains skills specifically for GitHub Copilot integration with HELIX CLI.

## Available Copilot Skills

- **copilot-react**: React/TypeScript component suggestions
- **copilot-discord**: Discord bot command suggestions  
- **copilot-web**: Web component and page suggestions
- **copilot-desktop**: Electron/desktop app component suggestions
- **copilot-game**: Game engine script suggestions

Each skill provides Copilot with context about the project type and framework for better suggestions.
