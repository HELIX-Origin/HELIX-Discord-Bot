Self-hosted Discord bot

Feeds, stream alerts, guild tools, and a built-in web dashboard.

HELIX Discord Bot is a lightweight, self-hosted feed syndication engine built in TypeScript ESM. It delivers RSS/Atom feeds, custom CSS web scrapers, subreddit streams, and free games straight to Discord channels.

01

Overview

What it does

HELIX Discord Bot monitors RSS/Atom feeds, custom CSS web scrapers, subreddit streams, and free-game promotions, and delivers rich Discord embeds straight to your server channels and threads.

It ships with a built-in web dashboard with Discord OAuth2 sign-in, SQLite persistence, Light/Dark themes, and zero frontend npm dependencies.

📰

Feeds & scrapers

RSS, Atom, and JSON feeds, CSS-selector scrapers, and a 700+ preset news catalog.

🎮

Free games

Giveaways from Epic Games, Steam, GOG, Humble, Itch.io, and more.

📢

Stream alerts

YouTube and Twitch live and upload alerts for your community.

🛡️

Guild administration

Moderation, welcome messages, support tickets, roles, and voice controls.

02

Capabilities

Feature breakdown

📡 Content delivery

  1. RSS, web scrapers & news catalog

    RSS/Atom/JSON feeds, CSS-selector scrapers for sites without RSS, single-newest-post delivery, and rate-limit shield.

  2. Reddit feeds

    Subreddit and user feeds with Pure Image and Standard RSS modes, animated GIF support, and NSFW age-restriction enforcement.

  3. Thread delivery

    Deliver each feed into its own dedicated thread, auto-created in the feed's channel.

🤖 Community tools

  1. Moderation

    Slash commands such as /warn, /kick, /ban, /purge, /lock, and /slowmode.

  2. Welcome system

    Customizable welcome announcements with placeholders, plain text or embed format, and live preview.

  3. Ticket system

    A button prompt that opens dedicated support threads and pings your support role.

🖥️ Web dashboard

  1. Discord OAuth2 sign-in

    Guild administrators manage feeds, alerts, and settings for the servers they administer.

  2. Live Discord previews

    Preview embeds, welcome messages, and ticket prompts before posting, with Light/Dark themes.

03

Deployment

Get started

Prerequisites

  1. Node.js 22.9.0 or higher Required

    Required for the native node:sqlite module.

  2. A Discord application Required

    Register one on the Discord Developer Portal.

Install & run

  1. 1. Clone & configure 
    git clone https://github.com/HELIX-Origin/HELIX-Discord-Bot.git
cd HELIX-Discord-Bot
cp .env.example .env

    Fill in DISCORD_TOKEN, DISCORD_CLIENT_ID, and DISCORD_CLIENT_SECRET in .env.

  2. 2. Build & start 
    npm install
npm run build
npm start

    Open http://localhost:3131 and select Log In with Discord.

  3. 3. Production deployment

    See Deployment & Hosting for Docker Compose, Linux systemd, Windows, and cloud PaaS guides.
