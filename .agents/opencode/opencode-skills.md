# Opencode Skills

This directory contains skills specifically for opencode configuration and management.

## Available Opencode Skills

- **opencode-init**: Initialize opencode configuration and folder structure
- **opencode-configure**: Configure opencode settings and preferences
- **opencode-skill-add**: Add new skills to the opencode system
- **opencode-skill-remove**: Remove skills from the opencode system
- **opencode-plan-create**: Create new plan tracking files
- **opencode-bug-report**: Report and track bugs
- **opencode-template-use**: Use existing templates
- **opencode-template-create**: Create new template files

Each skill provides detailed instructions for managing opencode-specific functionality within HELIX CLI.
